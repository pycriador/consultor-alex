Classes de Serviço

Infraestrutura de TI sob medida para o seu porte

Definimos o nível de proteção ideal para cada negócio — da operação essencial à alta disponibilidade corporativa.

Classe 1 — Infraestrutura

Básico Funcional

Para pequenos cartórios. Objetivo: operar com segurança mínima e continuidade.

Energia e Ambiente

  • Aterramento elétrico funcional
  • Nobreak (UPS) para equipamentos críticos
  • Autonomia para desligamento seguro
  • Equipamentos em local minimamente protegido

Rede

  • Internet funcional (≥ 2 Mbps ou compatível)
  • Roteador com controle de acesso
  • Switch básico
  • Cabeamento organizado

Segurança de Rede

  • Firewall básico (roteador ou appliance)
  • Bloqueio de acessos externos desnecessários
  • Antivírus em todos os dispositivos

Segmentação

  • Separação básica
    • Rede interna
    • Atendimento / visitantes

Backup

  • Backup automático diário
  • Cópia externa (HD ou nuvem)
  • Backup isolado do ambiente principal
  • Teste de restauração anual

Continuidade

RTOaté 24h
RPOaté 24h

Monitoramento

  • Logs básicos de acesso
  • Registro de falhas críticas
Classe 2 — Infraestrutura

Padrão Profissional

Para empresas de médio porte. Objetivo: segurança estruturada + controle.

Energia e Ambiente

  • Aterramento com laudo
  • Nobreak com maior autonomia
  • Rack organizado
  • Ambiente controlado (temperatura/acesso)

Rede

  • Internet ≥ 10 Mbps (ou compatível com RPO/RTO)
  • Link secundário (recomendado)
  • Switch gerenciável
  • Cabeamento estruturado

Segurança de Rede

  • Firewall com inspeção de tráfego
  • Regras de acesso documentadas
  • Antivírus corporativo
  • Atualizações de segurança ativas

Segmentação (obrigatório)

  • VLAN configurada
  • Separação
    • Administrativo
    • Atendimento
    • Dispositivos externos

Backup

  • Backup completo + incremental
  • Backup criptografado
  • Backup em nuvem (preferencial)
  • Monitoramento de falha de backup
  • Teste de restauração anual documentado

Continuidade

RTOaté 24h
RPOaté 12h

Infraestrutura de Dados

  • Armazenamento com redundância (RAID ou equivalente)
  • Recuperação rápida documentada

Monitoramento

  • Logs de
    • Acesso
    • Alteração
    • Tentativas de invasão
  • Retenção mínima de 5 anos
Classe 3 — Infraestrutura

Alto Nível Corporativo

Para empresas de grande porte. Objetivo: alta disponibilidade + segurança avançada.

Energia e Ambiente

  • Aterramento com laudo técnico
  • Nobreak + redundância elétrica
  • Ambiente controlado (climatização)
  • Controle de acesso físico restrito
  • Proteção contra incêndio

Rede

  • Internet ≥ 50 Mbps (ou equivalente)
  • Link redundante obrigatório
  • Balanceamento de links
  • Switch gerenciável com alta capacidade

Segurança de Rede

  • Firewall avançado (NGFW ou equivalente)
  • IDS/IPS ativo
  • Inspeção profunda de tráfego
  • Monitoramento contínuo

Segmentação

  • VLAN estruturada
  • Segmentação completa
    • Servidores
    • Usuários
    • Atendimento
    • Convidados

Backup

  • Backup contínuo ou alta frequência
  • Backup geograficamente distribuído
  • Backup criptografado
  • Monitoramento em tempo real
  • Teste de restauração semestral

Continuidade

RTOaté 8h
RPOaté 4h

Infraestrutura de Dados

  • Alta disponibilidade (HA)
  • Failover automático ou rápido
  • Ambiente redundante (local ou nuvem)

Monitoramento

  • Logs avançados (infra + rede)
  • Correlação de eventos
  • Retenção mínima de 5 anos
  • Monitoramento ativo de ameaças

Segurança Operacional

  • Gestão de vulnerabilidades
  • Correção rápida de falhas
  • Plano de resposta a incidentes
